# LFCR Events Scraper

A service that scrapes onchain events generated by LI.FI FeeCollector contracts on various blockchains and stores these events in a database. Part of the onchain-fee-collection-reporting monorepo.

## Overview

The `@jabba01/lfcr-events-scraper` package scans blockchain networks for events emitted by LI.FI's FeeCollector contracts, processes the event data, and stores it in a database for later analysis and reporting.

This service can be used in two ways:

1. As a standalone application
2. Integrated into other services, such as the `fees-reporter-api` package that exposes a REST API

## Installation

This project uses pnpm as the package manager. To install dependencies:

```bash
pnpm install
```

## Standalone Mode

When run in standalone mode, the application connects to a database, scrapes events from a specified blockchain, and stores the event data.

The default entry point (`main.ts`) initializes the database connection and starts scraping events from the Polygon chain.

## Integration

To use this package in another application:

```typescript
import { DatabaseConnector } from '@jabba01/lfcr-database'
import { startScraping } from '@jabba01/lfcr-events-scraper'
import { ChainKey } from '@lifi/types'

// Initialize database connection
await DatabaseConnector.init()

// Start scraping events from a specific blockchain
const result = await startScraping(ChainKey.ETH)

// Process the results
console.log(`Scraping completed with result: ${JSON.stringify(result)}`)

// Close database connection when done
DatabaseConnector.close()
```
