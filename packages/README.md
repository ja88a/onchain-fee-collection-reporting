# LI.FI Fee Collection Reporting Packages

This directory contains the various packages that make up the LI.FI onchain fee collection reporting system. Each package serves a specific purpose in the overall architecture.

## Core Packages

### [Common](./common)

**Purpose**: A shared library of utilities and data models used across all other packages in the monorepo.

**Description**: Sets of data structures and utilities used by the FeeCollector offchain services, providing a consistent foundation for all other packages.

### [Database](./database)

**Purpose**: Database connectivity and persistence layer.

**Description**: MongoDB database client for the LI.FI FeeCollection Reporter offchain service, handling all data storage and retrieval operations.

## Business Logic Packages

### [Events Scraper](./events-scraper)

**Purpose**: Blockchain event scanning and data collection.

**Description**: Service that scrapes onchain events generated by LI.FI FeeCollector contracts on a given blockchain and stores these events in a database. Can be run standalone or integrated with other services.

### [Fees Reporter](./fees-reporter)

**Purpose**: Reporting on collected fees and data computation.

**Description**: Service that processes the collected fee events and generates comprehensive reports about fees collected by integrators, including calculations of LI.FI's protocol share.

## API Packages

### [Fees Reporter API](./fees-reporter-api)

**Purpose**: HTTP REST API for accessing fee collection data.

**Description**: Backend service exposing a REST API for reporting fees collected onchain by the LI.FI protocol. Provides endpoints for retrieving reports and triggering blockchain scanning.

## Development Tools

### [Tools Repo](./tools-repo)

**Purpose**: Shared development utilities and configurations.

Contains several subpackages:

- **[lib-config-eslint](./tools-repo/lib-config-eslint)**: Shared ESLint configurations for consistent code style.
- **[lib-config-typescript](./tools-repo/lib-config-typescript)**: Shared TypeScript configurations.
- **[lifi-contract-typings-feecollector](./tools-repo/lifi-contract-typings-feecollector)**: TypeScript definitions for the LI.FI FeeCollector smart contracts.

## Architecture Overview

The system follows a modular architecture:

1. **Events Scraper** collects raw fee collection events from blockchains
2. Events are stored in the database via the **Database** package
3. **Fees Reporter** analyzes and generates reports from the stored events
4. **Fees Reporter API** exposes this functionality through a REST interface
5. **Common** provides shared utilities used by all packages
6. **Tools Repo** contains development and build utilities

## Development

Each package can be developed independently but may require other packages to function properly. Refer to the individual package README files for specific development instructions.
